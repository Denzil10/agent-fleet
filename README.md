# agent-fleet

An unattended multi-lane agent system, explained with its own live numbers: architecture, run outcomes, real examples, and the decision log of how it was steered.

Page: https://denzil10.github.io/agent-fleet/ · Portfolio: https://denzil10.github.io/

The numbers are generated from the fleet's run logs and git history as aggregate counts. The decision log and examples are hand-picked excerpts from the same sources, with product, platform and lane names redacted. The runtime itself stays private.
