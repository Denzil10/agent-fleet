Built in public · AI engineering

An unattended agent fleet,
held to evidence.

I design and run a multi-lane autonomous agent system on one machine. Each lane researches, builds and ships small products with no human in the loop. The products are the testbed. The work is the engineering that makes unsupervised agents reliable: verifiable claims, mechanical guards, model tiering, and failure handling that doesn't depend on the model behaving.

Architecture

One hourly runner. Deterministic gates run before any model is called, and a verifier checks everything a model wrote before it's committed.

Decision log

How the fleet was steered: what the signal was, what changed, and what that bought.

    Principles that held up

    Capability, not judgement

    If an agent must not do something unattended, remove the permission. Don't ask it nicely.

    Claims carry their proof

    A status is a pointer to a live check, or it's quarantined.

    Deterministic where possible

    Reading numbers, pacing and publishing are scripts. The model plans and builds.

    Fail loud, once

    A stuck lane parks and files one blocker, instead of burning runs in silence.
